🌍 World Weather Map

OpenWeatherMap の API キーが設定されていません。以下の手順で設定してください。

📋 ステップ 1 — API キーを取得する（無料・5分）
1
OpenWeatherMap にアクセス openweathermap.org を開き、右上の Sign Up をクリックします。
2
登録フォームを入力して「Create Account」
  • Username — 任意のユーザー名（英数字）
  • Enter email — メールアドレス
  • Password / Repeat Password — パスワード（8文字以上）
  • 利用規約の同意チェックボックス（2つ）に ✓ を入れる
入力後、Create Account ボタンをクリック。
3
用途アンケートが表示されたら 「How and where will you use our API data?」という画面が出ます。
個人利用なら Other → Save、または Cancel でスキップしてかまいません。
4
確認メールを開いて認証 「Please verify your email」メールが届きます。
Verify Email ボタンをクリックして認証を完了してください。
5
My API keys を開く ログイン後、右上の ユーザー名 をクリック →
メニューの My API keys を選択。
6
API キーをコピー 「Default」という名前の 32文字の英数字キーが表示されています。
コピーして次のステップで使用します。
⏱ 新規登録直後は API キーが有効になるまで最大 2 時間 かかる場合があります。
📝 ステップ 2 — .env ファイルに API キーを記述する
プロジェクトの .env ファイルを開く プロジェクトのルートフォルダにある .env ファイルをテキストエディタで開いてください。
コピーしたキーを貼り付けて保存する your_key_here の部分を取得した API キーに書き換えてください。
# OpenWeatherMap API キー
OPENWEATHER_API_KEY=your_key_here
サーバーを再起動する .env を保存したら、ターミナルでサーバーを再起動してください。
# ① 実行中のサーバーを止める
# ターミナルで Ctrl+C が効く場合はそれで止める
# 効かない場合は以下のコマンドで強制終了
kill $(lsof -ti :3000)

# ② 再起動
npm start
✅ サーバーを再起動すると、このページの代わりに地図画面が表示されます。
ブラウザで http://localhost:3000 を再度開いてください。
